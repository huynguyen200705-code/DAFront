Hướng Dẫn Cho Các Máy Tải App Về Đều Chạy Đồng Bộ Với Web API Này
Cung cấp đường dẫn API để mọi điện thoại Android/iOS khi tải app về đều kết nối dữ liệu chung
1. KẾT NỐI QUA MẠNG WI-FI (Nội bộ quán / Lớp học)

Cho điện thoại kết nối cùng Wi-Fi với máy tính này, dán link vào file .env của app:

BASE_URL=http://localhost:5276/api/
2. KẾT NỐI TỪ XA / 4G (Gửi app cho bất kỳ ai)

Chạy file start_public_tunnel.bat tại thư mục dự án để tạo link HTTPS công khai:

BASE_URL=https://[link-tunnel].trycloudflare.com/api/
Miễn phí 100%, ai ở đâu có mạng 4G cũng đều gọi món đồng bộ về máy chủ của bạn!

Chuyển Đổi SQLite / Microsoft SQL Server

                                    
Trong file appsettings.json, bạn có thể dễ dàng chuyển đổi CSDL theo ý muốn:

                                    
// Dùng SQLite (Mặc định, không cần cài SQL Server):
"UseSqlite": true

// Chuyển sang Microsoft SQL Server:
"UseSqlite": false,
"ConnectionStrings": {
  "DefaultConnection": "Server=.\\SQLEXPRESS;Database=RestaurantPOS_DB;Trusted_Connection=True;TrustServerCertificate=True"
}
